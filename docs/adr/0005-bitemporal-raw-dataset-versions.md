# 0005. Bitemporal raw-данные и dataset version как манифест

**Статус:** принято

## Контекст
Raw candles не должны изменяться (§5.2), experiment должен воспроизводиться при изменении истории поставщиком (§68).

## Решение
Raw-строки никогда не изменяются и не удаляются: `data_import_id`, `superseded_by_import_id`. Импорт, принёсший иные OHLCV для существующей свечи, создаёт **conflict**, который применяется только после подтверждения в Import UI. **Dataset version** — неизменяемый манифест (инструмент + TF + диапазон + набор импортов), создаётся автоматически при каждом принятом импорте. UI работает с последней версией; experiment/backtest закрепляют свою.

Цены: `NUMERIC(18,8)` в raw, `double precision` в derived.

## Последствия
Версии дешёвые (без копирования данных). Запросы к свечам учитывают фильтр по активным импортам версии.
