# 0005. Bitemporal raw-данные и dataset version как манифест

**Статус:** заменён ADR-0028 (2026-10-01); сохранён как история решений

## Контекст
Raw candles не должны изменяться (§5.2), experiment должен воспроизводиться при изменении истории поставщиком (§68).

## Решение
Raw-строки никогда не изменяются и не удаляются: `data_import_id`, `superseded_by_import_id`. Импорт, принёсший иные OHLCV для существующей свечи, создаёт **conflict**, который применяется только после подтверждения в Import UI. **Dataset version** — неизменяемый манифест (инструмент + TF + диапазон + набор импортов), создаётся автоматически при каждом принятом импорте. UI работает с последней версией; experiment/backtest закрепляют свою.

Цены: `NUMERIC(18,8)` в raw, `double precision` в derived.

## Последствия
Версии дешёвые (без копирования данных). Запросы к свечам учитывают фильтр по активным импортам версии.

## Уточнения (реализация)

- **Принятие конфликтов оформляется отдельным импортом-разрешением** (`kind = conflict_resolution`, `resolves_import_id`). Новые строки получают его id, а замещаемые — `superseded_by_import_id` = его id. Если записывать их под исходным импортом, уже созданные dataset version изменились бы задним числом.
- **Содержимое версии.** Свеча входит в версию, если её импорт в манифесте и она не замещена импортом из того же манифеста. Манифест, при котором для одной свечи видно несколько строк (пропущено разрешение), отклоняется при создании.
- **Версия создаётся** как «последняя версия + импорт» (`extend_dataset_version`), только для успешно завершённых (`completed`) импортов.
- **Инварианты на уровне БД:** триггер запрещает менять и удалять raw-свечи (разрешено один раз проставить `superseded_by_import_id`) и менять/удалять версии и их манифесты; частичный уникальный индекс гарантирует одну активную строку на свечу; CHECK на OHLC и объём есть и у raw-свечей, и у конфликтов.
- Конфликт хранит новое значение в `import_conflicts`; при принятии замещается **текущая** активная строка (если она уже равна принимаемому значению — конфликт закрывается без изменений).
