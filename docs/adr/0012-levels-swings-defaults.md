# 0012. Swing, Fibonacci и уровни: умолчания v1

**Статус:** принято

## Решение
- Swing по умолчанию — ATR-ZigZag (1.5 × ATR14 того же TF); подтверждение — закрытие бара на расстоянии ≥ порога, `confirmed_at = close_time` этого бара. Второй алгоритм — fixed-window; процентный ZigZag — параметр.
- Fibonacci: одна автоматическая сетка на source TF (последний подтверждённый swing → экстремум текущего колена); новая сетка — новое событие. Ручные сетки не участвуют в статистике.
- Touch: заход в зону ± k·ATR и отбой ≥ m·ATR без закрытия за зоной (k=0.25, m=0.5 в конфиге). Закрытие за зоной — break. Состояния: active → broken (смена роли) / expired (`max_age`).
- Strength — вектор компонентов + агрегат v1 с вручную заданными версионируемыми весами. Подбор весов по outcomes — только отдельным experiment с train/test.
- Кластеризация зон — представление в контексте графика (порог в ATR TF графика).

## Реализация swing (#34)
- Движки событий `zigzag` (параметр `threshold`: `atr` — `atr_mult` × ATR(`atr_period`), либо `percent` — % цены экстремума) и `swing_fixed` (`window` баров с каждой стороны). Событие `swing`, `payload`: `type` (high/low), `price`, `timestamp` (бар-экстремум), `method`.
- ZigZag: кандидат колена — `detected`, сдвиг экстремума — `revised`, закрытие бара на расстоянии ≥ порога — `confirmed` (`confirmed_at = close_time`) и новый кандидат в обратную сторону. Пока ATR не прогрет, подтверждений нет; первое колено определяется первым разворотом от бегущего максимума.
- Fixed-window подтверждает экстремум через `window` баров (`available_at` = закрытие этого бара); на плато берётся первый бар.

## Реализация market structure (#35)
- Движок `market_structure` (параметры как у `zigzag`) строится поверх подтверждённых точек ZigZag. `structure_point` — метка HH/LH/HL/LL относительно предыдущей точки того же типа; `trend_state` — смена состояния: uptrend (HH+HL), downtrend (LH+LL), иначе range. BOS/CHoCH не входят в MVP.

## Реализация pivot (#36)
- Движок `pivot` (`formula`: classic/fibonacci/woodie/camarilla, флаги `daily`/`weekly`). Периоды — торговый день (`trading_day`) и ISO-неделя торгового дня. Событие `pivot` с предыдущими High/Low/Close и PP, R1–R3, S1–S3; `applies_to` — первый торговый день нового периода.
- Движок узнаёт о завершении периода по первому бару следующего, поэтому `available_at` — закрытие этого бара (не позже), а не закрытие последнего бара периода: раньше знать нельзя без календаря будущих баров.
