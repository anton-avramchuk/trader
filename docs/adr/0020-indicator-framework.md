# 0020. Фреймворк индикаторов: плагины-машины, кэш, контрактный тест

**Статус:** принято

Реализует [ADR-0003](0003-causal-event-log.md), [ADR-0009](0009-mtf-projection.md) и [ADR-0010](0010-derived-persistence.md) для индикаторов.

## Плагин (`trader_engine.indicators`)
- Индикатор — подкласс `Indicator` с метаданными (`name`, `title`, `version`, `pane`: `price` / `separate`, `outputs`), моделью параметров `Params` (Pydantic) и **каузальной машиной** `update(bar) -> значения выходов`. Batch, replay и продолжение хвоста — один код.
- `warmup_bars` — сколько баров нужно до первого валидного значения; до этого выходы `None` («невалидно», не показываются и не участвуют в расчётах). `IndicatorSeries.valid_from = warmup_bars - 1`.
- Регистрация декоратором `@register`; ядро не меняется. `describe(plugin)` отдаёт UI JSON-схему параметров, значения по умолчанию, прогрев и выходы — форма добавления строится из схемы.
- Вход — `BarInput` (`float`-цены: индикатор не денежная сумма), включает `timestamp`, `close_time` и `trading_day` (для VWAP по календарю).

## Кэш
`IndicatorCache` — LRU по `(dataset_key, имя, версия, params_hash, source_tf)`. Запрос, продолжающий сохранённый (совпали отпечатки первого, среднего и последнего бара), продолжает **сохранённое состояние машины** и считает только новые бары; изменившиеся исходные бары (пересборка, новый масштаб continuous после ролла) — пересчёт с нуля, чужой хвост за продолжение не принимается. Индикаторы в БД не хранятся.

## Контрактный тест
`tests/indicators/test_contract.py` параметризован по `available()`: новый плагин попадает под него автоматически и обязан иметь значения `Params` по умолчанию. Проверяется:
1. прогрев: `None` строго до `valid_from`, после — конечные числа;
2. префикс-инвариантность (hypothesis): `f(data[:t])[-1] == f(data)[t]`;
3. продолжение хвоста из кэша = расчёт с нуля;
4. независимость состояния после `snapshot()`.

## Последствия
- Онлайн-проверка (`replay`, #32) применяется ко всему реестру теми же средствами.
- Изменение алгоритма плагина повышает `version` — ключи кэша не пересекаются.

## Набор первой версии (#26–#28)
| Группа | Плагины | Соглашения |
|---|---|---|
| Тренд | `sma`, `ema`, `wma`, `vwap` | EMA затравлена SMA первых `period` баров; WMA — веса 1…period; VWAP — типичная цена `(H+L+C)/3`, накопление сбрасывается со сменой **торгового дня календаря**, нулевой объём даёт типичную цену |
| Импульс | `rsi`, `roc`, `macd` | RSI — сглаживание Уайлдера (первые средние простые, 50 при нулевых прирос­те и убытке); MACD — три выхода `macd/signal/histogram`, валидны одновременно (прогрев `slow + signal − 1`) |
| Волатильность | `atr`, `bollinger` | ATR — Уайлдер, TR первого бара `H−L`; Bollinger — генеральное σ (ddof = 0), выходы `middle/upper/lower` |
| Объём | `volume_ma`, `relative_volume`, `obv` | Relative Volume = объём / среднее за `period` (включая текущий), нулевое среднее → 1; OBV — первый бар равен своему объёму |

Тест-векторы посчитаны независимо от кода (вручную и отдельной эталонной реализацией в тесте, напр. RSI: первое значение ряда StockCharts = 70,4641).
