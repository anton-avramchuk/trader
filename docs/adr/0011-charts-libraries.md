# 0011. Библиотеки графиков

**Статус:** принято

## Решение
- Ценовой график и панели (Volume, RSI) — **TradingView Lightweight Charts v5** в тонкой Angular-обёртке; зоны, Fibonacci, точки паттернов, траектории — через primitives/custom series. Атрибуция TradingView по лицензии Apache-2.0.
- Статистика (распределения, equity, перцентили) — **ECharts** (`ngx-echarts`).
- Plotly не используется.
