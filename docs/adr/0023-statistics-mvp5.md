# 0023. Historical Statistics (MVP-5): outcomes, baseline, доверительные интервалы

**Статус:** принято (реализация — MVP-5; решения по итогам раунда проектирования, issue #43)

Развивает ADR-0013 (горизонты в барах торгового времени, флаги пересечений, de-overlap, block bootstrap, baseline «случайная точка в том же режиме», пессимистичный неоднозначный бар).

## Решение

**Для каких событий.** Вхождения паттернов (ADR-0022) и события уровней (касание, пробой, ADR-0012). Swing, pivot и fibonacci-сетки в MVP-5 не участвуют.

**Точка входа.** Close бара, на котором событие стало известно (`available_at`): `confirmed` для паттерна, `touch`/`break` для уровня. Заглядывания вперёд нет — вход совпадает с моментом, когда сигнал виден пользователю. Для кандидатов (`detected`) вход — close бара обнаружения; в выборке они помечены `state=candidate` и включаются только явным фильтром.

**Исход (outcome)** считается на каждом горизонте из набора **5, 10, 20, 50 баров** торгового времени TF события (набор настраивается в запросе). Для вхождения хранится вектор:
- `return` — доход к close горизонта в направлении события (bullish — рост, bearish — падение);
- `mfe` и `mae` — максимальная благоприятная и неблагоприятная экскурсия от входа до горизонта по high/low;
- единицы — **ATR на момент входа** (основная метрика, сравнима между инструментами и режимами) и **проценты** (рядом, для наглядности);
- для паттерна: `target_hit` и `invalidated_hit` — что произошло раньше в окне горизонта (цель и уровень отмены берутся из события); оба в одном баре — пессимистично (сначала отмена) + флаг `ambiguous_bar` и отдельная строка в отчёте;
- флаги `crosses_session_gap`, `crosses_weekend`, `crosses_roll` по окну; горизонт, не доходящий до конца данных, — `censored` (в агрегаты не входит).

Для события уровня направление задаёт роль: касание поддержки / пробой сопротивления вверх — bullish, зеркально — bearish; «отбой» и «пробой» — разные группы.

**Режим.** Тренд (по `market_structure`: вверх / вниз / боковик, на момент входа) × волатильность (терциль ATR/цена относительно истории инструмента и TF). Режим определяется только по данным до входа.

**Baseline.** Случайные точки того же инструмента и TF с тем же режимом, тем же направлением и теми же горизонтами; подбор с фиксированным seed, вне окон реальных событий. Статистика показывается как разница «паттерн − baseline» с CI, а не голые проценты.

**De-overlap.** Окно равно горизонту: события одного инструмента/TF/направления ближе друг к другу, чем горизонт, считаются одним (остаётся первое). Каждый горизонт прореживается своим окном. Эффективный размер выборки — число непересекающихся событий; показывается рядом с сырым N.

**Доверительные интервалы.** Block bootstrap по времени (блоки подряд идущих событий, фиксированный seed, 95%). Малая выборка (эффективный N ниже порога) — предупреждение в ответе и UI, без «точных» чисел.

**Хранение.** Outcomes и статистика **не персистятся**: считаются на лету из `engine_events` и свечей, с кэшем по `(dataset_version, движок, версия, отпечаток параметров, фильтры)`. Отступление от строки spec §60 («персистятся … outcomes»): принято сознательно ради простоты и воспроизводимости; при медленных запросах на больших историях — отдельная задача на материализацию (тогда ключ кэша станет ключом таблицы).

**Фильтры и группировки.** Тип паттерна, направление, состояние (confirmed / invalidated / ложный пробой; candidate — по флагу), инструмент/root, TF, диапазон качества, режим, период. Отменённые и ложные вхождения входят в выборку с фильтром и показываются отдельной долей (`invalidated_rate`, `false_breakout_rate`) — так виден риск, а не только успех.

**API.** `GET /stats/outcomes` — агрегаты по фильтрам (медиана, среднее, доля успеха, MAE/MFE, CI, N и эффективный N, baseline, предупреждения); `GET /stats/occurrence` — исходы одного вхождения (по клику).

**UI.** Статистика по клику на паттерн или уровень в Chart/Replay: блок «Исторически» в панели деталей — N / эффективный N, медианный доход и MFE/MAE по горизонтам, доля цели и отмены, сравнение с baseline и CI, предупреждение о малой выборке; переключатель единиц ATR/%. Отдельная страница Research — позже (MVP-8).

**Тесты.** Unit на синтетических барах (направление, ATR/% единицы, MFE/MAE, флаги, неоднозначный бар, censoring); leakage — исход не зависит от будущего сверх горизонта, режим и baseline — только от данных до входа; de-overlap и эффективный N на крафтовых наборах; bootstrap детерминирован при фиксированном seed; интеграция с PostgreSQL на цепочке движков; UI в Playwright.

## Декомпозиция
1. Ядро outcomes: вход, горизонты, return/MAE/MFE в ATR и %, флаги пересечений, цель/отмена, неоднозначный бар, censoring.
2. Outcomes событий уровней (касание/пробой, направление по роли).
3. Режим (тренд × волатильность) и baseline «случайная точка в том же режиме».
4. Статистика: de-overlap, эффективный N, block bootstrap CI, агрегаты, предупреждения.
5. API `/stats/outcomes` и `/stats/occurrence`: выборка событий из лога, кэш, фильтры.
6. UI: блок «Исторически» по клику на паттерн/уровень.
7. Тесты: leakage, синтетика, регрессия, интеграция.
