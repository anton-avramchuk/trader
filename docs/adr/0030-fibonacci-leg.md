# 0030. Fibonacci: сетка на значимой ноге

**Статус:** принято (меняет ADR-0012 в части движка `fibonacci`)

## Проблема
Сетка строилась по ноге «последний подтверждённый swing → экстремум текущего колена» и пересматривалась на каждом новом экстремуме кандидата ZigZag. Итог: любое малейшее движение давало сетку, причём сетку самой коррекции (её откаты бесполезны), а нормальная импульсная нога с коррекцией, которая только развивается, не отображалась.

## Решение
Движок `fibonacci` версии 3 (снапшоты `fibonacci-*-v3`):
- Сетка строится только по **подтверждённым** swing ZigZag; бегущее колено её не двигает.
- В окне из последних `window` (20) подтверждённых swing берётся размах «минимум ↔ максимум»; нога идёт от более раннего экстремума к более позднему. Откат считается от её конца — это и есть зона, где может закончиться текущая коррекция.
- Нога должна быть не короче `min_leg_mult` (2.0) порогов ZigZag, иначе сетки нет: мелкие колебания не создают сетку.
- Новая нога — `detected`; нога выросла от того же начала (новый максимум в тренде) — `revised` той же цепочки.
- `atr_mult` ZigZag для этого движка по умолчанию 2.0 (при 1.5 нога короче и сетки чаще). Уровни `fib` в движке `levels` по-прежнему строятся по `fib_levels` от своих двух swing и не затронуты.

## Последствия
- На регрессионной серии событий стало 5 вместо 199.
- Старые прогоны `fibonacci` версии 1 остаются как есть; новые считаются по версии 2.
- Параметры `window`, `min_leg_mult` можно подстроить через `engine.run`.

## Уточнение: окно 20, а не 8
На SBER 1d после обвала июля консолидация дала много swing, и при окне 8 вершина (~328) выпала из окна: нога начиналась с промежуточной, более низкой вершины. Окно 20 swing удерживает доминирующий экстремум. Версия 3 из-за смены значения по умолчанию.

## Уточнение: окно 100 (версия 4)
На GAZP 1d между доминирующим хаем (~185) и текущим минимумом лежит больше 20 swing (длинная консолидация), и хай снова выпадал из окна. Окно по числу swing — по сути «глубина памяти», поэтому по умолчанию оно 100 (максимум 500): нога берётся как размах по всей значимой истории. Версия 4 из-за смены значения по умолчанию; `window` можно уменьшить через `engine.run`.
