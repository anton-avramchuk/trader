# 0008. Торговый календарь с правилами по датам действия

**Статус:** заменён ADR-0028 (2026-10-01); сохранён как история решений

## Контекст
С 23.03.2026 FORTS работает в режиме единой торговой сессии (07:00–23:50 МСК, вечерняя сессия относится к текущему дню); ранее вечерняя сессия относилась к следующему торговому дню. Есть выходные сессии (сб/вс 10:00–19:00).

## Решение
`TradingCalendar` у root: правила с датами действия (сессии, принадлежность вечерней сессии, клиринги, выходные сессии) + таблица праздников; редактируется в UI.
- 1d/1w — по торговому дню/неделе биржи; intraday TF выравниваются от начала торгового дня; неполные бары помечаются флагом.
- Выходные сессии хранятся в raw, по умолчанию исключаются из continuous (`include_weekend_sessions = false`).
- Ожидаемые разрывы не считаются missing intervals.
- Хранение в UTC, отображение в МСК.
