# 0009. Правила multi-timeframe отображения

**Статус:** принято

## Решение
- Source TF задаётся у каждого индикатора/уровня в UI; расчёт — по свечам source TF.
- Старший TF на младшем графике — ступенькой; значение меняется в `available_at` старшего бара; формирующийся старший бар не участвует. Предварительные значения не показываются (в MVP).
- **Младший TF на старшем графике запрещён.**
