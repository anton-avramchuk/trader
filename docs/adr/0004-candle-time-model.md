# 0004. Временная модель свечи

**Статус:** принято

## Решение
- `timestamp` = open time (UTC).
- `close_time` хранится явно: `min(open + duration, конец сессии по календарю)` — бары могут быть обрезаны сессией.
- `available_at` свечи = `close_time`; любое derived-значение на свече имеет `available_at >= close_time`.
- Формирующиеся бары в расчёты не попадают никогда; в live только отображаются.
- `event_outcomes` имеют собственный `available_at` (outcome горизонта n известен через n баров); forecast as-of `t` использует только созревшие outcomes.

## Последствия
Вычисление `available_at` не зависит от предположения о фиксированной длительности бара.
