# 0029. Шум уровней S/R: слияние, простой, фильтры, окно свечей

**Статус:** принято

## Проблема
На длинной истории график тонет в линиях: каждый подтверждённый swing давал отдельный уровень, swing-уровни жили до `max_age=1000` баров, на график шли 12 сильнейших со всей истории (далёкие от цены занимали места), близкие уровни разных источников рисовались рядом.

## Решение
**Движок `levels` (версия 2, снапшоты `levels-*-v2`):**
- `cluster_k` (по умолчанию 0.5·ATR, 0 — выкл.): swing в пределах `cluster_k`·ATR от активного swing-уровня не создаёт новый уровень, а подтверждает ближайший — событие `revised` с `change=merged`. Касанием это не считается (`touches` и статистика касаний не меняются), но простой сбрасывается.
- `max_idle` (по умолчанию 300 баров, 0 — выкл.): swing-уровень, к которому цена не возвращалась (касание или подтверждение) столько баров, истекает — `invalidated`, `reason=idle`. Pivot, prev и fib заменяются по источнику и простою не подвержены.
- Для уровней `atr_mult` ZigZag по умолчанию 2.0 (у разметки структуры остаётся 1.5): уровням нужны более значимые экстремумы.
- Формула силы v1 не менялась.

**Окно свечей (`engine.run`):** параметр задачи `last_bars` — сколько последних свечей использовать (по умолчанию 1000, 0 — вся история). Окно сдвигается с новыми барами, поэтому прогон в режиме `auto` обычно начинается заново; смена окна — тоже новый прогон. В Visual replay окно не применяется (`last_bars=0`): иначе прошлое было бы пустым. Бэктест читает свечи сам и параметра не использует.

**UI (фильтр представления, события не меняются):** на график и в список идут активные уровни не дальше N·ATR от последней цены (по умолчанию 20), без дублей ближе 0.5·ATR (остаётся сильнейший), не более `perSide` (4) выше и ниже цены, силой не ниже порога; fib- и pivot-уровни скрыты по умолчанию (у них свои слои). ATR(14) считается по загруженным свечам графика. В панели слоёв — выбор расстояния, числа уровней, порога силы, показ fib/pivot и числа свечей для расчёта.

## Последствия
- Снапшоты и регрессионные числа по levels (stats, analogues, backtest) пересчитаны; число сигналов уровней снизилось.
- Confluence-зоны (ADR-0012) по-прежнему считаются по активным уровням прогона; слияние лишь уменьшает их число.
