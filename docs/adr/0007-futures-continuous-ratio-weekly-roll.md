# 0007. Фьючерсы: root / contract / continuous, ratio-склейка, ролл по границе недели

**Статус:** принято

## Решение
- Root → Contract → Continuous series. Ключ контракта `(root, expiration_date)`; SECID и коды провайдеров — в `contract_provider_ids`. Контракты подтягиваются из ISS по коду актива, редактируются вручную.
- Ролл за N торговых дней до экспирации, **в начале торговой недели** — все TF (включая 1w) переключаются одновременно, недельная свеча не смешивает контракты. Ролл по объёму/OI не используется (известен только постфактум).
- Склейка **ratio**: масштабно-инвариантные величины (доходности, ATR-нормализация, паттерны) не зависят от числа последующих роллов.
- `roll_events` хранятся с `available_at`.
- Движки работают по continuous; бэктест исполняет в реальном фронтовом контракте с издержками ролла.
- Дневная история `step_price` по контракту; PnL — в USD и в ₽.

## Последствия
Абсолютные уровни в continuous пересчитываются коэффициентом при отображении. Outcomes через ролл помечаются `crosses_roll`.
