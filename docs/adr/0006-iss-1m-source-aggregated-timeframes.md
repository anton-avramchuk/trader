# 0006. MOEX ISS 1m как источник истории; отдельно хранящиеся TF

**Статус:** заменён ADR-0028 (2026-10-01); сохранён как история решений

## Контекст
Проверка провайдеров (29.09.2026): ISS бесплатно отдаёт 1m по истёкшим контрактам (~с 2020), но не имеет 15m/4h. T-Invest имеет все TF, но история истёкших фьючерсов не подтверждена. Граница торгового дня MOEX изменилась 23.03.2026.

## Решение
- ISS 1m — архивный raw (в UI не показывается).
- TF **15m, 1h, 4h, 1d, 1w** собираются из 1m по торговому календарю и **хранятся отдельно** (`provenance = aggregated(iss_1m)`). Каждый движок использует только свечи своего source TF.
- T-Invest — live, paper/live торговля и сверка; его свечи текущего дня замещаются ISS ночной задачей.
- Finam и прочие — через CSV-мастер.
- Первая задача MVP-1b — проверить историю истёкших контрактов в T-Invest.

## Последствия
TF согласованы между собой по построению. Бесплатный ISS имеет задержку — для live нужен T-Invest.
