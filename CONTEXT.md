# CONTEXT — глоссарий домена

Термины, которые используются в коде, API, UI и документации. Решения — в [`docs/adr/`](docs/adr/), требования — в [`docs/spec.md`](docs/spec.md).

## Инструменты

- **Root** — базовый актив фьючерса (например, NG, BR, GOLD). Заводится пользователем в UI: биржа, валюта котировки, tick size, торговый календарь, правило ролла, `include_weekend_sessions`.
- **Contract** — конкретная серия фьючерса с датой экспирации. Идентифицируется парой `(root, expiration_date)`; SECID и коды провайдеров — атрибуты (`contract_provider_ids`), потому что SECID повторяется раз в 10 лет.
- **Continuous series** — derived-ряд root, склеенный из контрактов по правилу ролла.
- **Roll event** — момент переключения continuous-серии на следующий контракт. Всегда в начале торговой недели; хранит ratio-коэффициент и `available_at`.
- **Ratio adjustment** — склейка умножением истории на отношение цен контрактов в момент ролла; сохраняет процентные изменения.
- **Front contract** — контракт, на который указывает continuous-серия в данный момент; в нём исполняются сделки бэктеста.
- **Step price** — стоимость шага цены в ₽; меняется ежедневно, хранится историей по контракту.

## Время

- **Trading calendar** — правила сессий root с датами действия + праздники. Определяет торговый день, торговую неделю, ожидаемые разрывы.
- **Trading day** — торговый день биржи; границы определяются правилом календаря, действующим на эту дату (до 23.03.2026 вечерняя сессия относилась к следующему дню).
- **Trading week** — пн–пт торговые дни (выходные сессии по умолчанию исключены).
- **Expected gap** — разрыв по расписанию (ночь, выходные, клиринг); не является missing interval.
- **Missing interval** — отсутствие свечей там, где календарь ожидает торги. Для ISS это «минуты без сделок или без данных»: ISS не отдаёт минуты без сделок.
- **Special trading day** — выходной, торгующийся как обычный день (рабочая суббота-перенос): окна берутся из будней действующего правила.
- **Auction minute** — минута аукциона открытия (06:59, 08:59, 09:59); её сделки лежат в свече этой минуты, поэтому окно сессии её включает.
- **Calendar era** — период, в котором расписание сессий неизменно; правила календаря — это эпохи с датами действия (12 эпох с 2020 года, ADR-0014).
- **open time / `timestamp`** — время открытия свечи (UTC).
- **`close_time`** — время закрытия свечи с учётом обрезки сессией; хранится явно.
- **`available_at`** — момент, начиная с которого значение/событие известно системе. Для свечи = `close_time`. Ничто не может использовать данные с `available_at > t` при расчёте на момент `t`.
- **`detected_at` / `confirmed_at`** — момент первого обнаружения кандидата и момент подтверждения события.
- **Forming bar** — незакрытая свеча; в расчёты не попадает никогда.
- **Warmup** — число баров (`warmup_bars`), необходимое индикатору для валидного значения; до него значение не показывается и не используется.

## Таймфреймы

- **Timeframe (TF)** — 15m, 1h, 4h, 1d, 1w. Все хранятся отдельно; строятся агрегацией 1m ISS по торговому календарю.
- **Raw 1m** — архивный источник истории из MOEX ISS; в UI не показывается.
- **Source TF** — TF, по свечам которого считается индикатор/уровень/структура.
- **Chart TF** — TF открытого графика.
- **MTF projection** — отображение значения source TF на графике chart TF. Разрешено только если source TF ≥ chart TF; значение отображается ступенькой и меняется в `available_at` старшего бара.
- **Incomplete (partial) bar** — бар короче номинальной длительности: обрезан сессией, клирингом или границей сетки; помечается флагом `is_partial`.
- **Bar anchor** — локальное время (07:00 МСК), от которого каждый календарный день строится сетка баров.
- **Bar slot** — ячейка сетки: `start` (open time бара), `close_time`, торговый день, `is_partial` (ADR-0014).
- **Session window** — непрерывное окно торгов в локальном времени; вечернее окно старого режима относится к следующему торговому дню (`next_day`).

## Данные

- **Provider** — источник данных (MOEX ISS, T-Invest, CSV). Реализует `MarketDataProvider`.
- **Data import** — одна операция импорта с `data_import_id`, отчётом и ошибками.
- **Bitemporal raw** — raw-строки не изменяются и не удаляются; новая версия значения помечает старую `superseded_by_import_id`.
- **Resolution import** — импорт (`kind = conflict_resolution`), под которым записываются принятые значения конфликтов; замещённые строки помечаются его id.
- **Conflict** — импортированное значение, отличающееся от уже принятого для той же свечи; применяется только после подтверждения пользователем.
- **Dataset version** — неизменяемый манифест (инструмент + TF + диапазон + набор импортов), однозначно восстанавливающий набор свечей. Создаётся при каждом принятом импорте.
- **Provenance** — происхождение derived-свечей (например, `aggregated(iss_1m)`).
- **Import preset** — сохранённый `FileMapping` (сопоставление колонок файла); встроенные — `finam`, `finam_no_header`, `iso_utc`.
- **Loaded window** — окно дат, уже загруженное у поставщика (по завершённым импортам, `params.window`); загрузка возобновляется с первого незагруженного куска.
- **Reconciliation** — сверка наших свечей со свечами другого провайдера (T-Invest); расхождения — в отчёт, не исправляются.

## Вычисления

- **Causal algorithm** — алгоритм вида `update(bar) -> events`, использующий только прошлое. Batch = прогон по истории.
- **Event log** — неизменяемый журнал событий движков с `available_at`, `algorithm_version`, `params_hash`, `dataset_version_id`.
- **Revision / invalidation** — новое событие, пересматривающее прежнее (сдвиг последнего колена ZigZag, отмена кандидата паттерна). Старые события не изменяются.
- **Prefix invariance** — свойство `f(data[:t])[-1] == f(data)[t]`; обязательный тест каждого алгоритма.
- **Visual replay** — просмотр истории с курсором `t`: сервер отдаёт snapshot as-of `t`.
- **Online replay** — повторный прогон алгоритмов свеча за свечой и сравнение с event log (проверка отсутствия look-ahead).
- **Snapshot as-of t** — свечи, события и значения с `available_at <= t`.

## Структура и уровни

- **Swing point** — локальный экстремум; по умолчанию ATR-ZigZag (1.5 × ATR14), подтверждается закрытием бара на расстоянии ≥ порога.
- **Market structure** — последовательность HH/HL/LH/LL и состояние тренда (uptrend/downtrend/range).
- **Level** — ценовая зона `[price_low, price_high]` с source TF, источниками и состоянием.
- **Touch** — заход цены в зону ± k·ATR с отбоем ≥ m·ATR без закрытия за зоной.
- **Break** — закрытие бара source TF за зоной; уровень становится `broken` и может сменить роль (support ↔ resistance).
- **Expired level** — уровень без касаний дольше `max_age` баров своего TF.
- **Strength** — вектор компонентов уровня + агрегат с вручную заданными, версионируемыми весами. Техническая характеристика, не прогноз.
- **Confluence zone** — кластер уровней, объединённых по порогу `distance / ATR` TF графика; представление, не сохраняемая сущность.
- **Fibonacci structure** — автоматическая сетка на source TF от последнего подтверждённого swing до экстремума текущего колена; ручные сетки в статистике не участвуют.
- **Pivot structure** — PP, R1–R3, S1–S3 по торговому дню/неделе; формула конфигурируется.

## Статистика и бэктест

- **Outcome** — фактическое поведение цены после события на горизонте n баров торгового времени; имеет свой `available_at` и флаги `crosses_session_gap`, `crosses_weekend`, `crosses_roll`.
- **De-overlap** — прореживание перекрывающихся событий; даёт эффективный размер выборки.
- **Baseline** — безусловное распределение «случайная точка в том же режиме» для сравнения.
- **Ambiguous bar** — бар, в котором достигнуты и стоп, и тейк; решается пессимистично и помечается.
- **Experiment** — исследование с закреплённой dataset version, версиями алгоритмов и периодами train/validation/test.
- **Chart profile** — сохранённый набор индикаторов, слоёв и стилей графика (глобальный или для root).
